# Llamatik AI

> Local-first AI SDKs, apps, and developer tools for Kotlin Multiplatform.

Llamatik AI is an open-source ecosystem focused on bringing powerful AI capabilities directly to your devices using Kotlin Multiplatform and modern on-device inference engines.

We build tools that make local AI practical across Android, iOS, desktop, server, and web applications.

## ✨ What We Build

### 🧠 AI Runtime Libraries
Multiplatform Kotlin wrappers around:
- llama.cpp
- whisper.cpp
- stable-diffusion.cpp

Designed for:
- Android
- iOS
- JVM/Desktop
- WASM/Web (experimental)

---

### 🔧 SDKs & Agentic Tooling
We are expanding Llamatik into a complete SDK for building:
- local-first AI apps
- AI agents
- developer tools
- multimodal experiences
- offline AI workflows

---

### 💻 Applications
The ecosystem includes:
- Cross-platform local AI apps
- Developer tooling
- IntelliJ/Android Studio integrations
- Experimental local-first IDE experiences
